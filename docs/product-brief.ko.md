# 제품 개요

## 문제

사용자는 자기계발 시간을 확보해도 다음과 같은 판단 때문에 시작이 지연됩니다.

- 오늘 어떤 프로젝트를 해야 하는가?
- 어디부터 다시 시작해야 하는가?
- 어느 정도 해야 끝난 것인가?
- 막혔을 때 조사해야 하는가, 다른 일을 해야 하는가?

일반적인 할 일 목록과 알림은 작업을 기억하게 하지만 위 판단을 제거하지 못합니다.

## 해결 방향

Growth Time OS는 매 세션의 결과를 다음 세션의 입력으로 연결합니다. 사용자가 앱을 열었을 때 선택 목록 대신 실행 가능한 `지금` 카드 한 장을 보여줍니다.

### 연결 카드의 필수 정보

- 프로젝트
- 실행 시점과 장소
- 이어받을 파일·문서·페이지
- 직전 결과
- 2분 안에 시작할 수 있는 첫 행동
- 한 세션 안에 판정 가능한 완료 조건
- 결과 검증 방법
- 막힐 때 수행할 우회 행동
- 완료 증거
- 다음 카드

## 주요 상태

```text
NOW      지금 실행할 카드, 최대 1장
NEXT     순서가 정해진 다음 카드, 최대 3장
WAITING  외부 답변이나 자료를 기다리는 카드
DONE     완료 증거가 남은 카드
```

## 자동 진행 규칙

```text
완료
→ 증거 저장
→ NEXT 첫 카드를 NOW로 승격

시간 종료 + 미완료
→ 남은 부분을 한 세션 크기로 분리
→ 분리된 카드를 NOW로 유지

10분 이상 막힘
→ 카드에 정의된 우회 행동 실행

우회 행동도 불가능
→ WAITING으로 이동
→ NEXT 첫 카드를 NOW로 승격

하루 누락
→ NOW 카드와 순서를 변경하지 않음
```

## 초기 사용자 사례

### 이력서

```text
채용공고 요구역량 추출
→ 관련 경험과 수치 목록화
→ 경력 문장 작성
→ 요구역량 기준 수정
→ 최종 편집과 PDF 검사
```

### 대학원 원서

```text
요구조건 표 작성
→ 경험과 연구 관심 목록화
→ 질문별 개요
→ 문단 작성
→ 외부 피드백 반영
→ 제출본 검사
```

### 토익

```text
진단 문제
→ 오답 원인 분류
→ 약점 유형 연습
→ 시간 제한 혼합문제
→ 오답 재풀이
→ 주간 미니 테스트
```

### 개발 공부

```text
기능 완료 조건 작성
→ 최소 구현
→ 테스트
→ 실패 원인 수정
→ 전체 검증
→ 코드 정리와 기록
```

## 최소 기능 범위

초기 버전에서는 다음 기능만 구현합니다.

1. 프로젝트와 기본 실행 환경 설정
2. 카드 생성·수정·순서 지정
3. `NOW` 카드 단독 실행 화면
4. 완료, 막힘, 대기 처리
5. 다음 카드 자동 승격
6. 완료 증거와 실제 집중시간 기록
7. 주간 시작률·산출물 요약

초기 범위에서 제외합니다.

- 소셜 피드와 경쟁 순위
- 복잡한 캘린더 최적화
- 과도한 알림과 연속 달성 배지
- AI가 사용자 확인 없이 프로젝트 방향을 변경하는 기능
- 여러 생산성 도구를 한 번에 대체하는 기능

## 성공 지표

- 예정된 실행 기회 중 NOW 카드를 시작한 비율
- 앱을 연 뒤 첫 행동을 시작하기까지 걸린 시간
- 완료 증거가 첨부된 카드 수
- 미완료 카드가 다음 세션에서 재개된 비율
- 4주 후에도 유지되는 프로젝트 비율
