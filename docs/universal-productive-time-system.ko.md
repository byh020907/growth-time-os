# 범용 유익시간 운영체계

이 시스템은 성격이 다른 자기계발 작업을 같은 방식으로 운영하기 위한 템플릿이다. 구체적인 적용 예시는 토익 학습으로 통일한다.

핵심 흐름은 다음과 같다.

> 프로젝트 정의 → 이번 주 산출물 선택 → 고정된 시간에 실행 → 결과 증거 기록 → 다음 행동 예약

실제 하루에는 계획이나 우선순위 판단을 하지 않는다.

> `지금 카드 열기 → 첫 행동 실행 → 완료 또는 막힘 표시 → 다음 카드로 자동 이동`

## 1. 기본 운영 규칙

1. 동시에 `주력 프로젝트 1개 + 유지 프로젝트 1개`만 활성화한다.
2. 할 일은 시간이나 의도가 아니라 눈에 보이는 산출물로 적는다.
3. 매 세션이 끝날 때 다음 세션의 첫 행동을 적어 둔다.
4. 세션 시작 전 휴대폰과 불필요한 사이트 접근을 차단한다.
5. 정상 세션을 못 하는 날에는 최소 복구 세션을 실행한다.
6. 평가는 기분이 아니라 시작률, 산출물, 오류 수정량으로 한다.
7. 하루를 마칠 때 다음 세션의 `연결 카드`를 완성해 맨 앞에 둔다.
8. 다음 날에는 새 계획을 세우지 않고 연결 카드의 첫 행동부터 실행한다.

### 주력 프로젝트와 유지 프로젝트

- 주력: 마감이 있거나 집중적인 진전이 필요한 일. 주 3~5회 배정한다.
- 유지: 중단하면 손실이 큰 장기 학습. 주 1~2회 배정한다.
- 나머지 목표는 대기 목록에 둔다. 매일 여러 목표 사이에서 선택하지 않는다.

예시: 주력은 토익 실전 문제 풀이, 유지는 토익 단어 복습으로 둔다.

## 2. 프로젝트 카드

새로운 목표를 시작할 때 아래 항목을 한 번 작성한다.

```text
[프로젝트 이름]

완료 상태:
- 무엇이 존재하면 이 프로젝트가 끝난 것인가?

완료 기한:
- YYYY-MM-DD

완료 판단 기준:
- 품질이나 수량을 무엇으로 확인할 것인가?

현재 상태:
- 이미 가진 자료, 실력, 초안은 무엇인가?

부족한 것:
- 정보 / 지식 / 기술 / 피드백 중 무엇이 부족한가?

다음 이정표:
- 1~2주 안에 만들 중간 결과물은 무엇인가?

다음 물리적 행동:
- 지금 5분 안에 시작할 수 있는 가장 작은 행동은 무엇인가?
```

### 좋은 완료 상태의 예

| 분야 | 모호한 목표 | 좋은 완료 상태 |
|---|---|---|
| 토익 | 토익 공부하기 | 8주 동안 실전 모의고사 6회, 오답 재풀이 정답률 85% 달성 |

완료 판단 기준은 프로젝트 중간에 바뀔 수 있다. 단, 매일 바꾸지 않고 주간 점검 때만 수정한다.

## 3. 무결정 모드

### 하루에 허용되는 판단은 두 가지뿐이다

세션 중 사용자가 판단할 것은 다음 두 가지다.

1. 카드의 완료 조건을 충족했는가?
2. 정해진 우회 행동으로도 진행할 수 없는가?

그 외에는 기본 규칙이 대신 결정한다.

| 상황 | 자동 규칙 |
|---|---|
| 세션을 시작할 때 | `지금` 카드 한 장을 그대로 실행 |
| 카드가 일찍 끝났을 때 | 남은 시간이 10분 이상이면 `다음 1` 카드 시작, 아니면 종료 |
| 시간이 끝났지만 미완료 | 남은 일을 한 세션 크기로 잘라 같은 프로젝트의 다음 카드로 생성 |
| 10분 이상 막혔을 때 | 카드에 적힌 우회 행동 실행 |
| 우회 행동도 불가능할 때 | 필요한 질문·자료 요청 카드를 `대기`로 옮기고 `다음 1` 실행 |
| 하루를 놓쳤을 때 | 계획을 다시 짜지 않고 기존 `지금` 카드 유지 |
| 새로운 아이디어가 생겼을 때 | 대기 목록에 한 줄만 적고 현재 카드 계속 실행 |
| 여러 마감이 충돌할 때 | 주간 점검에서만 기한이 가까운 주력 프로젝트를 선택 |

### 한 번만 정하는 기본값

아래 값은 매일 고르지 않는다. 2주간 고정한 뒤 주간 점검에서만 바꾼다.

```text
기본 실행 신호: 평일 저녁 식사 정리 직후
기본 장소: 내 책상
정상 세션: 50분
최소 복구: 10분
주력 프로젝트: 1개
유지 프로젝트: 1개
환경 차단: 휴대폰 거실 + 방해 사이트 차단
```

### 금지되는 일일 질문

다음 질문은 세션 시작 시 하지 않는다.

- 오늘 무엇을 공부하지?
- 어떤 프로젝트가 더 중요하지?
- 몇 분 해야 하지?
- 어디부터 시작하지?
- 이 자료도 먼저 찾아봐야 하나?

이 질문들의 답은 `지금` 카드에 이미 들어 있어야 한다. 카드에 없다면 실행자의 문제가 아니라 카드 작성 문제로 보고 주간 점검 때 수정한다.

### 시작 절차: 60초

```text
1. 지금 카드 연다.
2. 카드의 이어받을 위치를 연다.
3. 휴대폰을 지정 장소에 둔다.
4. 카드의 첫 행동을 실행한다.
```

타이머 설정, 음악 선택, 책상 정리, 새 할 일 작성은 시작 절차에 넣지 않는다. 필요하면 미리 고정된 자동 설정을 사용한다.

## 4. 일을 네 가지 작업 모드로 분류하기

모든 세션은 아래 네 가지 중 하나를 선택한다.

### A. 조사 모드

필요한 정보와 요구조건을 수집한다.

- 시험 일정과 접수 조건 확인
- 반복되는 오답 유형의 문법 규칙 확인

종료 증거: 출처가 있는 요구조건 표, 비교표, 질문 목록.

조사는 시간 제한을 두고 반드시 다음 제작 행동으로 연결한다. 자료를 많이 모으는 것 자체는 진전으로 계산하지 않는다.

### B. 제작 모드

불완전하더라도 초안이나 작동하는 결과물을 만든다.

- 오답 원인표와 복습 카드 작성

종료 증거: 작성된 오답 원인표와 복습 카드.

### C. 연습 모드

자료를 보지 않고 문제를 풀거나 기술을 수행한다.

- 토익 문제 20개 시간 제한 풀이

종료 증거: 풀이 결과, 정답률, 문제당 시간.

### D. 검토·수정 모드

기준과 피드백에 따라 기존 결과물을 개선한다.

- 오답 원인을 분류하고 재풀이

종료 증거: 수정 전후 차이, 해결된 오류, 재검사 결과.

## 5. 주간 계획: 15분

주 1회 같은 요일에 다음 순서로 계획한다.

### 1단계: 지난주 증거 확인

- 예정한 세션 수 / 실제 시작한 세션 수
- 완성한 산출물
- 반복해서 발생한 방해요인 한 가지
- 다음 주에도 유지할 요소 한 가지

### 2단계: 이번 주 결과물 선택

이번 주에 반드시 남길 결과물을 최대 3개만 정한다.

```text
이번 주 결과물
1.
2.
3.
```

### 3단계: 한 주의 카드 사슬 만들기

```text
월: 연습 — 토익 Part 5 문제 20개 시간 제한 풀이
화: 검토 — Part 5 오답 원인 분류와 재풀이
수: 유지 — 토익 단어 30개 인출 복습
목: 연습 — 약점 유형 문제 20개 풀이
금: 검토 — 주간 미니 테스트와 반복 오답 집계
```

캘린더에는 `자기계발`이라고 쓰지 않는다. `작업 모드 + 종료 산출물`을 쓴다.

주간 계획 때 아래 조건을 만족하는 카드 3~5장을 순서대로 만든다.

- 각 카드의 파일·페이지·문제 범위가 지정되어 있다.
- 첫 행동과 완료 조건이 적혀 있다.
- 앞 카드의 결과가 다음 카드의 입력이 된다.
- 실행 순서를 미리 정해 `다음 1`, `다음 2`, `다음 3`에 넣는다.

이후 일주일 동안 순서를 다시 고르지 않는다. 긴급한 외부 마감 변화가 없는 한 카드 순서를 유지한다.

### 토익 기본 카드 사슬

처음에는 아래 순서를 그대로 사용하고 필요한 카드만 건너뛴다.

```text
진단 문제 풀이
→ 오답 원인 분류
→ 가장 큰 약점 유형 연습
→ 시간 제한 혼합문제
→ 오답 재풀이
→ 주간 미니 테스트
```

주간 미니 테스트가 끝나면 가장 많이 반복된 오답 유형이 다음 주 첫 연습 카드가 된다.

## 6. 범용 50분 세션

50분은 시작을 위한 기본값이며 절대적인 최적 시간은 아니다. 2주간 운영한 뒤 30~75분 범위에서 조정한다.

### 0~5분: 시작

- 휴대폰을 손이 닿지 않는 곳에 둔다.
- 필요한 파일과 자료만 연다.
- 이번 세션 종료 시 남아 있어야 할 산출물을 한 줄로 적는다.

```text
오늘의 산출물:
```

### 5~35분: 핵심 작업

선택한 작업 모드 하나만 실행한다. 조사와 제작, 학습과 정리를 계속 전환하지 않는다.

### 35~45분: 검증과 피드백

- 문서: 요구조건이나 평가표와 비교한다.
- 시험: 채점하고 오답 원인을 분류한다.
- 조사: 출처와 누락된 요구조건을 확인한다.

### 45~50분: 증거와 다음 행동

```text
실제 산출물:
발견한 오류 또는 부족한 점:
다음 세션의 첫 행동:
```

`다음 세션의 첫 행동`은 동사와 대상을 포함해 5분 이내 시작할 수 있도록 쓴다.

- 나쁨: 토익 공부 계속하기
- 좋음: Part 5 오답 1번부터 정답을 가리고 다시 풀기

## 7. 토익 세션 예시

```text
오늘의 산출물: 문제 20개 풀이, 오답 원인 분류, 틀린 문제 재풀이

5~10분: 이전 오답을 자료 없이 재풀이
10~35분: 시간 제한을 두고 새 문제 풀이
35~45분: 채점하고 오답을 지식/해석/시간/부주의로 분류
45~50분: 다시 볼 문제와 복습 날짜 기록
```

측정값:

- 처음 풀이 정답률
- 오답 재풀이 정답률
- 문제당 평균 시간
- 반복되는 오답 원인

## 8. 실행 문장과 복구 문장

### 정상 실행 문장

```text
[반복되는 생활 사건]이 끝나면 [고정 장소]에서 휴대폰을 치우고,
[미리 정한 첫 행동]을 시작한다.
```

예:

> 평일 저녁 식사를 정리하면 책상에서 휴대폰을 치우고, 오답노트의 지정된 문제부터 다시 푼다.

### 최소 복구 문장

```text
정상 세션을 놓쳤다면 [대체 시점]에 10분 동안
[가장 작은 산출물]을 만들고 기록한다.
```

최소 복구 세션의 예: 토익 오답 세 문제를 정답을 가리고 다시 푼다.

최소 복구는 정상 세션을 계속 축소하기 위한 제도가 아니다. 끊어진 흐름을 다음 세션으로 연결하는 장치다.

## 9. 다음 날로 이어지는 연결 카드

하루 실행하고 다음 날 멈추는 가장 큰 원인 중 하나는 다음 날 다시 `무엇부터 하지?`를 결정해야 한다는 점이다. 이를 막기 위해 매 세션 마지막 5분에 다음 세션 카드를 만든다.

### 카드 보드 구조

보드에는 네 칸만 둔다.

```text
[지금] 1장만 허용
[다음] 최대 3장
[대기] 외부 답변이나 자료를 기다리는 카드
[완료] 결과 증거가 남은 카드
```

- `지금` 카드가 다음 날 시작 화면이다.
- `지금`에는 항상 카드 한 장만 둔다. 두 장 이상이면 시작 전에 다시 선택해야 한다.
- 세션을 마치면 완료 카드를 옮기고 `다음`의 첫 카드를 `지금`으로 올린다.
- 다음 카드가 없다면 세션을 종료하기 전에 방금 한 일에서 자연스럽게 이어지는 카드를 만든다.
- 새로운 아이디어는 바로 실행하지 않고 `다음`이나 별도의 대기 목록에 넣는다.

### 범용 연결 카드 양식

```text
┌─────────────────────────────────────┐
│ 프로젝트:                           │
│ 카드 제목: [동사] + [구체적 대상]  │
│ 실행 시점/장소:                     │
│ 예상 세션: 기본 1회                 │
├─────────────────────────────────────┤
│ 이어받을 위치                       │
│ 파일/문서/페이지/문제 번호:         │
│ 직전 결과 한 줄:                    │
├─────────────────────────────────────┤
│ 첫 행동 — 2분 안에 시작 가능하게    │
│                                     │
├─────────────────────────────────────┤
│ 이번 카드의 완료 조건               │
│                                     │
├─────────────────────────────────────┤
│ 검증 방법                           │
│                                     │
├─────────────────────────────────────┤
│ 막힐 때 우회 행동                    │
│                                     │
├─────────────────────────────────────┤
│ 완료 증거:                          │
│ 완료일:                             │
│ 다음 카드:                          │
└─────────────────────────────────────┘
```

### 카드 작성 기준

좋은 카드는 다음 날의 기억과 판단을 요구하지 않는다.

- 파일이나 페이지를 찾을 수 있다.
- 첫 행동이 2분 이내에 시작 가능하다.
- 한 세션 안에 끝낼 수 있다.
- 완료 여부를 다른 사람도 판정할 수 있다.
- 막혔을 때 조사만 하다가 끝나지 않도록 우회 행동이 있다.
- 필요한 자료와 프로그램이 카드에 연결되어 있다.

예:

```text
프로젝트: 토익 8주 계획
카드 제목: Part 5 오답 12개 원인 분류 후 재풀이
이어받을 위치: 오답노트 2026-08-30 / 문제 1~12
직전 결과: 12개 중 어휘 5, 문법 4, 시간 부족 3개
첫 행동: 정답을 가리고 1번 문제부터 다시 푼다
완료 조건: 12개 재풀이와 오답 원인 태그가 끝난다
검증 방법: 재풀이 정답률과 문제당 시간을 기록한다
막힐 때 우회 행동: 해설을 읽고 규칙을 한 문장으로 적은 뒤 유사문제 1개 풀이
```

### 세션 인계 절차

세션 마지막 5분은 다음 순서로 사용한다.

1. 현재 카드에 완료 증거를 붙인다.
2. 완전히 끝나지 않았다면 남은 일을 그대로 적지 말고 한 세션 크기로 다시 자른다.
3. 파일·페이지·문제 번호 등 재개 위치를 기록한다.
4. 다음에 클릭하거나 작성할 첫 행동을 적는다.
5. 다음 카드를 `지금` 칸에 놓은 뒤 세션을 종료한다.

이 절차를 지키면 다음 날의 시작은 다음처럼 단순해진다.

> 지금 카드 열기 → 이어받을 위치 열기 → 첫 행동 실행

### 하루를 건너뛴 경우

카드의 날짜를 계속 다시 정하지 않는다. 못 한 날에도 `지금` 카드는 그대로 유지한다. 다음 실행 기회에 같은 카드에서 재개한다.

- 놓친 날을 보충하기 위해 두 세션을 몰아서 하지 않는다.
- 연속 기록이 끊긴 것을 실패로 평가하지 않는다.
- 같은 카드가 두 번 연속 시작되지 않았다면 카드 크기, 첫 행동, 환경 차단 중 하나를 수정한다.
- 정상 세션이 어렵다면 카드의 `막힐 때 우회 행동`만 수행하고 다음 카드를 만든다.

### 카드 크기 규칙

- 한 카드가 정상 세션 1회를 넘기면 두 장으로 나눈다.
- 10분 이내 끝날 일은 관련 카드에 묶되, 시작 장벽이 큰 일은 별도 카드로 둔다.
- `조사하기`, `공부하기`, `작성하기`처럼 끝을 판정할 수 없는 제목은 금지한다.
- 제목에는 대상과 완료 가능한 동작을 함께 쓴다.

예:

- 나쁨: 토익 공부하기
- 좋음: Part 5 오답 12개를 원인별로 분류하고 정답을 가린 채 재풀이

## 10. 세션 기록표

```text
| 날짜 | 프로젝트 | 모드 | 예정/실제 시작 | 집중 시간 | 산출물 | 다음 행동 |
|---|---|---|---|---:|---|---|
| | | | | | | |
```

기록은 1분 안에 끝낸다. 감정이나 자기평가는 선택사항이고, 산출물과 다음 행동은 필수다.

## 11. 주간 진단 규칙

문제가 생기면 의지력을 평가하지 말고 아래 순서로 원인을 찾는다.

### 시작 자체를 못 했다

- 시간대가 다른 일정과 자주 충돌하는가?
- 첫 행동이 여전히 모호하거나 큰가?
- 휴대폰·게임·영상 접근이 그대로 열려 있는가?
- 작업 파일과 자료를 찾는 데 시간이 드는가?

조치: 시간, 신호, 장소, 첫 행동 중 하나만 수정한다.

### 앉았지만 결과물이 없다

- 조사와 제작을 한 세션에서 계속 전환했는가?
- 오늘 산출물이 너무 컸는가?
- 어려운 지점에서 자료 수집으로 회피했는가?

조치: 한 세션 한 모드 원칙을 적용하고 산출물을 절반으로 줄인다.

### 공부했지만 기억이나 실력이 늘지 않는다

- 읽기와 시청이 대부분이었는가?
- 자료 없이 회상·수행하는 시간이 있었는가?
- 채점, 테스트, 외부 피드백이 있었는가?
- 같은 실수를 분류하고 다시 시도했는가?

조치: 학습 시간을 더 늘리기 전에 인출·실전·피드백 비중을 늘린다.

### 일정은 지켰지만 지쳤다

- 수면이나 식사를 희생했는가?
- 주력 프로젝트가 둘 이상인가?
- 정상 세션을 놓친 다음 날 몰아서 보충했는가?

조치: 세션 수나 길이를 줄이고 주력 프로젝트를 하나로 제한한다.

## 12. 개인 효과 검증

### 1주 기준선

현재 방식으로 다음 세 가지를 기록한다.

- 예정 세션 중 실제 시작한 비율
- 완성한 산출물 수
- 학습 과제의 재시험·재수행 결과

### 4주 적용

이 운영체계를 그대로 적용하고 같은 지표를 기록한다.

다음 질문으로 판단한다.

1. 시작률이 실제로 높아졌는가?
2. 투입 시간당 산출물이 증가했는가?
3. 다음날 또는 다음 주 재수행 결과가 좋아졌는가?
4. 수면과 스트레스를 희생하지 않고 유지 가능한가?

성과가 없다면 시간을 더 투입하기 전에 가장 약한 연결고리 하나를 수정한다.

- 시작률 문제 → 실행 신호와 환경 차단 수정
- 산출물 문제 → 작업 크기와 모드 수정
- 학습성과 문제 → 인출·실전·피드백 수정
- 지속성 문제 → 세션 수와 주력 프로젝트 수 수정
