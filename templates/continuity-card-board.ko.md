# 유익시간 연결 카드 보드

## 지금 — 반드시 한 장만

```text
프로젝트:
카드 제목:
실행 시점/장소:
예상 세션: 기본 1회

이어받을 파일/문서/페이지:
직전 결과 한 줄:

첫 행동:
완료 조건:
검증 방법:
막힐 때 우회 행동:

완료 증거:
완료일:
다음 카드:
```

### 실행 버튼을 누른 뒤의 고정 절차

```text
카드 열기
→ 이어받을 위치 열기
→ 첫 행동 실행
→ 완료 조건 확인
→ 완료 증거 첨부
→ 다음 1 카드를 지금으로 이동
```

다른 카드 선택, 우선순위 재평가, 분량 결정은 하지 않는다.

## 대기

외부 답변, 추천서, 자료, 피드백처럼 내가 바로 진행할 수 없는 카드만 둔다.

```text
카드:
기다리는 대상:
확인할 날짜:
기다리는 동안 가능한 우회 행동:
```

## 완료

완료한 카드에는 결과 증거를 남긴다.

```text
완료일:
카드 제목:
결과 증거 또는 링크:
다음 카드로 넘긴 내용:
```

## 세션 종료 체크

- [ ] 현재 카드에 완료 증거를 남겼다.
- [ ] 다음 카드의 이어받을 위치를 적었다.
- [ ] 첫 행동이 2분 안에 시작 가능하다.
- [ ] 완료 조건을 판정할 수 있다.
- [ ] 막힐 때 우회 행동을 적었다.
- [ ] 다음 카드를 `지금` 칸에 놓았다.

## 기본 자동 규칙

```text
일찍 완료 + 10분 이상 남음 → 다음 1 시작
시간 종료 + 미완료 → 남은 부분을 다음 카드로 분리
10분 이상 막힘 → 우회 행동 실행
우회 행동도 불가 → 대기로 이동 후 다음 1 시작
하루 놓침 → 지금 카드 그대로 유지
새 아이디어 발생 → 대기 목록에 한 줄만 기록
```
