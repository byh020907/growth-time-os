Product Goal · Current Desired State

다음 행동을 다시 고르지 않는 성장 실행 시스템

Growth Time OS는 자기계발 시간을 확보한 사용자가 계획을 다시 세우지 않고, 준비된 NOW 카드 한 장의 첫 행동부터 바로 실행하고 다음 세션까지 끊김 없이 이어가게 한다.

Product Intent

Target User

여러 자기계발 목표를 진행하지만 매 세션마다 무엇을 할지, 어디서 재개할지, 언제 끝인지 판단하느라 시작이 늦어지는 개인 사용자.

Desired Outcome

사용자는 앱을 열고 한 장의 NOW 카드만 본다. 지정된 위치와 첫 행동을 따라 즉시 시작하고, 완료 또는 막힘을 기록하면 시스템이 이미 정한 순서의 다음 카드를 준비한다.

구체적인 적용 예시는 토익 학습만 사용한다. 제품 동작은 다른 자기계발 프로젝트에도 같은 규칙으로 적용된다.

Core User Loop

  1. NOW 열기
    선택 목록 대신 현재 카드 한 장을 본다.
  2. 위치 열기
    카드에 지정된 파일, 페이지 또는 문제 범위를 연다.
  3. 첫 행동
    2분 안에 시작 가능한 행동을 그대로 실행한다.
  4. 판정
    완료 조건 충족 또는 우회도 불가능한 막힘만 판정한다.
  5. 자동 연결
    증거를 남기고 정해진 다음 카드가 NOW로 승격된다.

Card States

NOW · 0..1장지금 실행할 전역 카드. 초기 상태와 모든 카드 처리 후에는 없을 수 있지만 두 장 이상일 수 없다.
NEXT · 0..3장프로젝트와 관계없이 실행 순서가 이미 정해진 전역 대기열.
WAITING우회 행동도 불가능하고 외부 답변, 자료 또는 피드백을 기다리는 카드.
DONE완료 시각과 비어 있지 않은 결과 증거가 남은 카드.

Product Requirements

Identifier는 Product Goal, Gap과 verification evidence를 연결하며 개발 순서나 과거 version을 뜻하지 않는다.

PG-001 · Focus

앱을 열면 NOW 한 장에 집중한다

  • 기본 실행 화면은 NOW 카드만 단독으로 보여 준다.
  • NOW에는 프로젝트, 제목, 예상 세션, 실행 시점과 장소가 표시된다.
  • NOW가 없으면 앱이 임의로 프로젝트를 고르지 않고 카드 사슬을 만들도록 안내한다.
  • NEXT나 다른 프로젝트를 고르는 control은 실행 화면에 노출하지 않는다.

PG-002 · Guided Setup

필수 정보를 질문 하나씩 입력한다

  • 프로젝트 생성, 카드 작성·수정과 미완료 인계는 한 번에 질문 하나만 보여 준다.
  • 답변 후 다음 질문에 자동으로 focus하고 현재 단계와 전체 진행률을 text로 보여 준다.
  • 이전 단계로 돌아갈 수 있고 선택 항목은 건너뛸 수 있다.
  • 짧은 입력은 Enter, 긴 입력은 명시된 keyboard shortcut으로 다음 단계에 진행한다.
  • 카드 한 장을 완성한 뒤에만 다음 카드 추가 또는 현재 사슬 저장을 선택한다.
  • 필수 답변이 비어 있으면 입력을 잃지 않고 같은 질문에서 수정 안내를 보여 준다.

PG-003 · Continuity

카드만으로 다음 세션을 재개한다

  • 카드는 이어받을 위치, 직전 결과, 2분 이내 첫 행동을 가진다.
  • 카드는 한 세션 안에 판정 가능한 완료 조건과 결과 검증 방법을 가진다.
  • 카드는 10분 막혔을 때 수행할 구체적인 우회 행동을 가진다.
  • 카드 제목은 대상과 완료 가능한 동작을 함께 표현한다.

PG-004 · Global Queue

프로젝트가 달라도 실행 순서는 하나다

  • 시스템 전체에서 NOW는 최대 한 장, NEXT는 최대 세 장이다.
  • 빈 보드에 만든 첫 카드는 NOW, 나머지는 입력 순서대로 NEXT가 된다.
  • 기존 NOW가 있으면 새 카드는 NEXT의 끝에 추가된다.
  • NEXT 순서는 사용자가 카드 사슬 화면에서만 미리 조정한다.

PG-005 · Complete

완료 증거를 남기고 자동으로 이어 간다

  • 사용자는 NOW 시작을 기록할 수 있다.
  • 완료에는 비어 있지 않은 결과 증거와 실제 집중시간을 남긴다.
  • 완료 카드는 DONE으로 이동하고 NEXT 첫 장이 같은 처리에서 NOW가 된다.
  • 이미 처리한 카드의 반복 동작은 새 NOW에 적용되지 않는다.

PG-006 · Block and Wait

막힘은 우회하고 외부 의존만 기다린다

  • 막히면 먼저 NOW에 적힌 우회 행동을 그대로 실행한다.
  • 우회도 불가능할 때 막힌 이유, 기다리는 대상과 선택적인 확인 날짜를 기록해 WAITING으로 보낸다.
  • WAITING 전환과 NEXT 첫 카드 승격은 함께 일어난다.
  • 대기 해제 시 NOW가 없으면 NOW, 있으면 NEXT 끝으로 돌아오며 NEXT가 가득 차면 명확히 거부한다.

PG-007 · Miss and Continue

놓친 날과 미완료가 순서를 깨지 않는다

  • 시간 경과나 하루 누락만으로 NOW, NEXT 순서 또는 날짜를 바꾸지 않는다.
  • 미완료 세션은 남은 일을 한 세션 크기로 다시 적고 같은 NOW를 유지한다.
  • 미완료 인계는 이전 실행을 닫고 다음 실행 기회를 새로 준비한다.
  • 놓친 시간을 보충하도록 여러 카드를 한꺼번에 강요하지 않는다.

PG-008 · Persistence

같은 기기에서 실행 맥락을 보존한다

  • 프로젝트, 카드 상태와 순서, 완료 증거와 실행 기록은 같은 browser와 device에서 다시 열어도 유지된다.
  • 저장 실패는 성공처럼 보이지 않고 현재 입력을 유지한 text error로 알린다.
  • 손상된 저장 data는 앱을 중단시키거나 잘못된 NOW를 만들지 않고 안전한 빈 상태로 복구한다.

PG-009 · Evidence Review

최근 실행을 증거로 검토한다

  • 최근 7일 실행 기회 대비 시작률을 보여 준다.
  • 완료 산출물 수, 집중시간과 WAITING 전환 수를 보여 준다.
  • 완료 카드의 프로젝트, 제목, 완료일과 증거를 확인할 수 있다.
  • 오래 유지된 NOW도 최근에 시작하거나 종료했다면 최근 기록에 포함한다.

PG-010 · Access

설치 없이 모바일과 데스크톱에서 실행한다

  • current desktop/mobile browser에서 핵심 loop를 수행할 수 있다.
  • 화면과 control은 text label 또는 accessible name으로 목적을 식별할 수 있다.
  • keyboard focus가 보이며 주요 작성과 실행 동작을 keyboard로 수행할 수 있다.
  • 좁은 화면에서 horizontal scroll 없이 핵심 action과 내용을 사용할 수 있다.

Screens and Information Priority

NOW

현재 카드의 이어받을 위치와 첫 행동을 가장 강하게 보여 주고 완료 조건, 검증 방법과 우회 행동을 함께 제공한다.

Card Chain

주간 결정 영역. 프로젝트와 카드 정보를 질문 하나씩 만들고 NEXT 순서와 WAITING 상태를 관리한다.

7-Day Review

감정 평가 대신 시작, 완료 산출물, 집중시간과 대기 전환의 최근 증거를 보여 준다.

Empty and Failure

NOW가 없을 때 임의 선택을 하지 않고 카드 사슬 작성을 안내한다. validation과 저장 실패는 원인과 복구 행동을 입력 가까이에 text로 표시한다.

Product Constraints and Scope

Must Remain True

  • 계정 생성, 설치와 network connection 없이 핵심 loop를 사용할 수 있다.
  • 사용자 실행 data는 명시적인 외부 기능이 생기기 전까지 해당 browser/device를 떠나지 않는다.
  • 알림, 연속 출석과 보상 장치보다 시작 마찰과 선택지 제거를 우선한다.
  • 사용자 확인 없이 프로젝트 방향이나 카드 순서를 자동 변경하지 않는다.

Out of Scope

  • cloud account, multi-device sync와 협업
  • 소셜 feed, 경쟁 ranking과 streak badge
  • 복잡한 calendar 최적화와 과도한 notification
  • 여러 생산성 도구를 한 번에 대체하는 범용 suite
  • AI가 확인 없이 목표나 우선순위를 바꾸는 동작
