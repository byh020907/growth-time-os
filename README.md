# Growth Time OS

이력서 작성, 대학원 원서, 시험 공부, 개발 공부처럼 성격이 다른 자기계발 작업을 하나의 카드 흐름으로 관리하는 프로젝트입니다.

핵심 목표는 사용자가 매일 `무엇을 해야 하지?`라고 판단하는 시간을 최소화하는 것입니다.

```text
지금 카드 열기
→ 지정된 위치 열기
→ 첫 행동 실행
→ 완료 또는 막힘 표시
→ 다음 카드로 이동
```

## 제품 원칙

- `지금` 카드에는 항상 한 장만 둡니다.
- 카드에는 이어받을 위치, 첫 행동, 완료 조건, 검증 방법을 포함합니다.
- 하루를 놓쳐도 기존 카드를 유지합니다.
- 우선순위와 작업 순서는 매일이 아니라 주간 계획에서 결정합니다.
- 시간 투입보다 결과 증거와 다음 행동을 남깁니다.
- 알림에 의존하지 않고 시작 마찰과 선택지를 줄입니다.

## 현재 단계

현재 저장소는 검증된 운영 원칙과 카드 템플릿을 정리한 초기 문서 단계입니다. 구현 기술과 배포 방식은 아직 결정하지 않았습니다.

다음 구현 단계에서는 아래 최소 흐름을 우선 검증합니다.

1. 프로젝트 생성
2. 카드 사슬 생성
3. `지금` 카드 한 장 표시
4. 완료·막힘 처리
5. 다음 카드 자동 승격
6. 실행 기록과 주간 검토
